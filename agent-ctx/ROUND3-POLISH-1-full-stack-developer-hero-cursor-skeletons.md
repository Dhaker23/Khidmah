- **Created `src/components/khidma/cursor-glow.tsx`** — `"use client"` component. Uses `useMotionValue` + `useSpring` (stiffness 150, damping 20, mass 0.3) for performant cursor tracking (no React re-renders on `mousemove`). Tracks pointer via a single `mousemove` window listener; on each event uses `e.target.closest("[data-cursor-glow]")` to decide whether to fade in. `setActive` uses the functional updater form and only updates when the boolean actually flips (avoids spurious renders). Initial state is off-screen (`x=-1000, y=-1000`) so the spring never appears at (0,0). `prefers-reduced-transparency` is detected via `window.matchMedia("(prefers-reduced-transparency: reduce)")` — the result is applied through `requestAnimationFrame(() => setSupportsTransparency(...))` to satisfy the project's `react-hooks/set-state-in-effect` ESLint rule. Reduced-motion users get nothing rendered. The glow itself is a `motion.div` with `mix-blend-mode: screen`, `pointer-events-none`, `z-30`, `size-[400px]`, `radial-gradient(circle, rgba(116,134,132,0.15) 0%, transparent 70%)`, opacity animated 0→1 with a 0.3s ease-out transition.
